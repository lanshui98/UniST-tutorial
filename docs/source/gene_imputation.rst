Gene Imputation
====
This tutorial performs continuous gene expression reconstruction via Graph Autoencoder (GAE) and Implicit Neural Network (INR) in both 2D and 3D spatial transcriptomics examples. We further describe how accuracy is quantitatively evaluated, between 
predicted and ground-truth gene expression at `Quantitative Assessment <https://unist-tutorial.readthedocs.io/en/latest/tutorial.html>`_.
